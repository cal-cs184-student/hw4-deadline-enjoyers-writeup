# Homework 4 write-up

Report authors: Arthur Yu and Wenxuan Yuan (Deadline Enjoyers).

Open `index.html` to view the report. It uses local images and CSS and needs no CDN, JavaScript, fonts, or build step.

The submission PDF is [hw4-writeup.pdf](./hw4-writeup.pdf).

- `assets/experiments.json` records scenes, simulation parameters, snapshot frames/times, shader names, and camera placement. Camera arrays contain target x/y/z, polar angle, azimuth, and distance.
- `assets/measurements/*.csv` contains sampled height and internal Verlet velocity diagnostics.
- `assets/custom-texture.png` is the custom color texture for the texture_1 slot.
- `assets/custom-height.png` is the non-default height field for the texture_2 slot. Bump/displacement figures use height scale 0.1 and normal scale 200.
- Diagnostic Ambient, DiffuseOnly, and Specular shaders are capture-only copies of the corresponding terms in the implemented Phong shader. No assignment source code is distributed here.

The PDF is generated by printing the same HTML with backgrounds enabled, A4 paper, and the included print CSS. The print layout has twelve report sections/pages. Inspect the resulting PDF before submission; submit it on Gradescope and assign pages to the corresponding rubric parts.

The public Pages URL is https://cal-cs184-student.github.io/hw4-deadline-enjoyers-writeup/. Publishing requires pushing the write-up repository. This preparation does not itself submit to Gradescope.
